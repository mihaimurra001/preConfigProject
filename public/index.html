            Ghid Detaliat: Instalare Universală vs Instalare pe Proiect
          

          

            Diferențele concrete de arhitectură, comenzi și locații de configurare pentru Claude Code CLI și Antigravity CLI.
          

        


        
        

          

            

              
              Instalare Universală (Globală)
            

            
    
              
  • Scop: Se aplică automat în toate sesiunile și proiectele de pe calculator.
    • 
              
  • Claude Code: ~/.claude/CLAUDE.md & ~/.claude/skills/
    • 
              
  • Antigravity: ~/.gemini/config/GEMINI.md & ~/.gemini/config/skills/
    • 
              
  • Când se recomandă: Reguli de conduită generală, identitatea de programator, scurtături preferate globale.
    • 
            

          


          

            

              
              Instalare pe Proiect (Locală)
            

            
    
              
  • Scop: Izolată în directorul proiectului; poate fi inclusă în Git pentru toată echipa.
    • 
              
  • Claude Code: ./CLAUDE.md & ./.claude/skills/
    • 
              
  • Antigravity: ./GEMINI.md, ./AGENTS.md & ./.agents/skills/
    • 
              
  • Prioritate: În Antigravity, setările din workspace au prioritate maximă (suprascriu setările globale).
    •

                addyosmani/agent-skills (Addy Osmani)
              
              

                42k+ ⭐ Skills & Workflows
                
                  
                
              

            

            

              Ce face: Colecție de 25 de abilități avansate de inginerie software. Folosește Progressive Disclosure (în contextul inițial intră doar numele și descrierea; instrucțiunile complete se activează la cerere sau când introduci o comandă).
            

            

              

                Comenzi cheie:
                • /spec - Specificații clare înainte de cod

                • /plan - Descompunere sarcini atomice

                • /build - Implementare incrementală

                • /test - TDD (Red-Green-Refactor)

                • /review - Verificare pe 5 axe
              

              

                Instalare CLI:
                • Universal: npx skills add addyosmani/agent-skills -g

                • Proiect: npx skills add addyosmani/agent-skills

                • Claude Plugin: /plugin install agent-skills@addy-agent-skills
              

            

          


          
          

            

              
                
                DietrichGebert/ponytail
              
              

                24k+ ⭐ Minimalist Code
                
                  
                
              

            

            

              Ce face: "The laziest senior dev in the room". Impune scara de priorități în 7 trepte: 1. YAGNI, 2. refolosire utilitar existent, 3. standard library, 4. API nativ de browser, 5. dependență deja instalată, 6. o singură linie, 7. cod minim. Rezultă în medie cu ~54% mai puțin cod generat.
            

            

              

                Antigravity CLI (agy):
                • Plugin nativ: agy plugin install https://github.com/DietrichGebert/ponytail

                • Pe proiect: regasit în .agents/rules/ponytail.md și AGENTS.md

                • Skills: /ponytail-review, /ponytail-audit
              

              

                Claude Code CLI:
                • Plugin marketplace: /plugin marketplace add DietrichGebert/ponytail apoi /plugin install ponytail@ponytail

                • Local: injectat în CLAUDE.md sau AGENTS.md
              

            

          


          
          

            

              
                
                headroomlabs-ai/headroom
              
              

                71.8k+ ⭐ Context & Token Compression
                
                  
                
              

            

            

              Ce face: Motor avansat de compresie semantică de context creat pentru agenți AI de codare. Comprimă log-uri lungi, ieșiri de consolă (stdout/stderr), diff-uri git gigantice și JSON-uri voluminoase cu 20–90% fără pierdere de informații critice (erori, stack traces). Oferă funcționalitatea CCR (Context Compression Retrieval) pentru restaurarea textului complet la cerere.
            

            

              

                Capabilități Cheie:
                • SmartCrusher: compactare JSON & tabele fără pierdere de chei

                • CodeCompressor: minimizare AST cod repetitiv

                • Kompress-v2: compresie log-uri cu păstrarea erorilor fatale

                • CCR: cache local & recuperare via headroom_retrieve
              

              

                Instalare & MCP Server:
                • CLI Tool: uv tool install headroom-ai[all]

                • MCP Server: uvx headroom-ai[all] mcp

                • Comandă Skill: /compress

                • Reguli: integrat în AGENTS.md & .agents/rules/headroom.md
              

            

          


          
          

            

              
                
                Graphify-Labs/graphify
              
              

                31k+ ⭐ Knowledge Graph & MCP
                
                  
                
              

            

            

              Ce face: Construiește un graf de cunoștințe deterministic folosind parsare AST cu Tree-sitter și clustering Leiden. Generează fișierul graphify-out/graph.json și vizualizator interactiv HTML. Rulează ca MCP Server pentru ca agentul să știe arhitectura fără să citească sute de fișiere brute.
            

            

              

                Instalare & Rulare:
                • CLI: pip install graphifyy && graphify install

                • Generare graf: /graphify . sau graphify .

                Configurare MCP Server:
                • Antigravity: .agents/mcp_config.json

                • Claude Code: .claude/settings.json

                • Server command: uv run --with graphifyy --with mcp -m graphify.serve

                Leonxlnx/taste-skill
              
              

                86k+ ⭐ Anti-Slop Discipline
                
                  
                
              

            

            

              Ce face: Previne "AI visual slop" (gradienturile generice violet/cyan, layout-urile monotone cu carduri centrate, lipsa de contrast real). Obligă AI-ul să definească o direcție vizuală puternică înainte de primul rând de CSS și introduce conceptul celor Three Dials (Variance, Motion, Density).
            

            

              

                The Three Dials:
                • DESIGN_VARIANCE (1-10): de la simetrie corporatistă la layout editorial îndrăzneț

                • MOTION_INTENSITY (1-10): de la tranziții statice la fizică de resorturi (springs)

                • VISUAL_DENSITY (1-10): de la pagină aerisită (Apple) la densitate B2B (Linear)
              

              

                Instalare:
                • Universal: npx skills add Leonxlnx/taste-skill -g

                • Pe proiect: npx skills add Leonxlnx/taste-skill

                • Antigravity Rule: integrat în .agents/rules/taste.md

                VoltAgent/awesome-design-md
              
              

                115k+ ⭐ Brand DESIGN.md Tokens
                
                  
                
              

            

            

              Ce face: Separă Design-ul de Cod prin standardul universal DESIGN.md. În timp ce AGENTS.md dictează cum scrie agentul cod, DESIGN.md dictează paleta de culori, fonturile, bordurile, spațierile și atmosfera vizuală a celor mai mari branduri tech (Linear, Apple, Stripe, Vercel etc.).
            

            

              

                Preseturile Suportate:
                • Linear: Dark mode obsidian, accente violet/lavender, precizie extremă

                • Apple: Sf Pro, claritate minimalistă, fundaluri pure, contrast perfect

                • Stripe: Indigo vibrant, gradiente subtile de încredere, carduri elegante

                • Vercel: Monocrom pur (alb-negru), tipografie Geist, grid tehnic
              

              

                Cum se aplică:
                • Fișierul DESIGN.md este generat direct în rădăcina proiectului.

                • Agentul (Claude Code sau Antigravity) îl citește automat ca referință de styling pentru orice componentă UI creată.
